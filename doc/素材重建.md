# 素材重建

Godot 平时读取已生成的剧情、声音和图集。修改地图的通道、角色对白或战斗队伍时，使用 `content/regions/<地区>/maps/` 中正在发行的文件。只想重画图像时，工具会保留这些手工调整。

## 选择上游与生成环节

Python 3.9+ 需要 Pillow、NumPy、FontTools。图鉴贴图宏展开需要系统 C 预处理器 `cc`，重新合成音频需要带 Vorbis 编码器的 FFmpeg。以下命令在仓库根目录执行。

```bash
python3 -m venv ../pokesaga-venv
source ../pokesaga-venv/bin/activate
python3 -m pip install Pillow numpy fonttools requests
python3 tools/fetch_sources.py
python3 tools/rebuild_assets.py all
```

上游仓库和提交固定在 [asset_sources.json](../tools/asset_sources.json)。默认输入目录为工程旁的 `pokesaga-sources/`，可用 `POKESAGA_SOURCES` 指向其他位置。各来源也支持独立覆盖，例如 `POKESAGA_CRYSTAL=/path/to/pokecrystal`。获取命令支持只写来源名，例如 `python3 tools/fetch_sources.py crystal firered`。生成可对另一份现有工程运行，例如 `python3 tools/rebuild_assets.py maps --project /path/to/copy`。

| 环节 | 素材与产物 |
| --- | --- |
| `maps` | pokecrystal 的 4×4 图块按显存区、逐图块配色、地区屋顶重画 377 张在用城都图，保留原始像素和游戏中的格宽。修复门点并从原事件更新中文告示与隐藏道具。pokefirered 提供草地属性和七岛海岸连接。再接入丰缘返程和世界路线。按最终碰撞、门点和地标生成各图的《绿宝石》场景及全景图底图，同时重建标题、人物和战斗场地。 |
| `icons` | 从 pokeemerald-expansion 道具表读取图像和调色板，生成背包图集和中文索引。 |
| `dex` | 用固定 PokeAPI CSV 建立编号、形态、中文名和原型关系。原版物种优先取《绿宝石》原色、异色与正背面图。按 pokeemerald-expansion 的物种声明补充后续物种和形态。PokeAPI/sprites 补充骑乘姿态和背面才能辨认的性别差异。本版收录 1,678 条形态展示数据。 |
| `font` | 从 Noto Sans CJK SC Regular 生成游戏中文子集。新增菜单或剧情用字后可重新运行。用系统无关的字形绘制“图鉴”“悖谬”等标题。 |
| `audio` | 从 13 首 MIDI 曲谱合成 BGM，另生成 16 个音效。发行素材保留原有 BGM 编码；FFmpeg 优先使用 libvorbis，本机只有内置 Vorbis 时用双声道编码，相同输入在同一套工具下可以重复生成。 |

原始城都转换器 `tools/gen_johto.py` 还会产出上游未采用的房间，并重新生成地区数据。做原始导入实验时，把 `POKESAGA_PROJECT` 指向实验工程。学习版在已有可编辑地图上运行 `maps`，保留关都故事、道馆战斗和渡轮等设计。
## 绿宝石地图与角色

未白镇与 101 号道路的地图尺寸、坐标和原版一致，按原版布局直接绘制。其他地图在本作的行走网格上重排《绿宝石》的地砖、房屋和家具，共覆盖 21 个地区的 1,230 张地图。

| 内容 | 从固定上游重建 |
| --- | --- |
| 房间、城镇和野外 | `python3 tools/bake_emerald_field.py` 读取 pret/pokeemerald 的地图布局、图块定义及调色板，生成 Godot 使用的图集与地图描述。门、楼梯、告示牌和领航员按游戏中已有交互点定位。 |
| 地区和道路 | 编辑 `tools/world/regions.txt` 中的城镇、道路和地标，然后运行 `python3 tools/build_world_routes.py`、`python3 tools/world/render_charts.py`、`python3 tools/bake_emerald_field.py`。世界图和各地区索引使用本作地图坐标。 |
| 标题与菜单 | `python3 tools/import_emerald_ui.py` 按原 GBA 图块顺序、翻转位和调色板组装烈空坐标题和宝可导航丰缘图。START 菜单采用《绿宝石》默认窗框的九块 8 像素图块。启动图标使用精灵球道具图，背包图取自男主角背包，队伍卡片底纹取自原队伍菜单。丰缘索引中的「丰缘地图」可查看原版导航图。 |
| 人物 | `python3 tools/import_official_chars.py` 导入《绿宝石》祐树行走帧、护士和各类 NPC。大木、关都道馆馆主及火箭队等专属角色取自《火红》。 |
| 宝可梦 | `python3 tools/import_dex_art.py` 编制正面、背面及其异色图集。用《绿宝石》现有图像表现对应物种与形态；后世代使用扩展素材。八个额外骑乘姿态有单独正面图，背面沿用同物种像素图。队伍、图鉴与对战读取同套图集，星星闪、方块闪和太晶效果在运行时单独绘制。 |
| 战斗场地 | `python3 tools/import_emerald_battle.py` 从原版图块重组草地、高草、沙地、海面、海底、洞穴、道馆和联盟等战场。 |

主要来源见 [pokecrystal](https://github.com/pret/pokecrystal)、[pokefirered](https://github.com/pret/pokefirered)、[pokeemerald](https://github.com/pret/pokeemerald/tree/9103e529c2fbdd7add4a1ff3350c6c1f92112c42)、[pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion)、[PokeAPI 数据](https://github.com/PokeAPI/pokeapi)、[PokeAPI 图像](https://github.com/PokeAPI/sprites) 与 [Noto CJK](https://github.com/notofonts/noto-cjk)。
