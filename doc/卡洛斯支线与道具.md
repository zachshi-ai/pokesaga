# 卡洛斯支线与道具

从地区转移器第一次前往卡洛斯时，先选寄存队伍或带队，再选《X》或《Y》。版本决定神兽和部分超级石。御三家决定冠军后游走的鸟宝可梦。卡洛斯的徽章、秘传许可和事件进度都记在同一份存档中。

## 冠军后按什么顺序走

1. 去密阿雷车站找布拉塔诺博士，拿ＴＭＶ自由票，搭车去奇楠市。
2. 在奇楠市对战宅邸登记队员，实际完成一场挑战。回来找莎莉娜对战，获胜得到阿勃梭鲁进化石。
3. 去百刻市的日晷找博士升级超级环。按设备本地时间，每晚 **20:00 至 20:59** 可在对应地点看到超级石闪光。
4. 回密阿雷帅哥事务所接委托。第一章的五张帅哥券分布在洋红广场宝可梦中心、棱镜塔、药草店、豪华酒店和美术馆。收齐后回办公室交券。小弥受惊时可选跳舞或微笑。
5. 随后依次追查车站的不良少年、美术馆被破坏的画、北大道的强化服、大酒店和弗拉达利研究所。第五章查完地下研究笔记、完成四场强化服战斗后，回事务所看信，再去美术馆和弗拉达利咖啡馆告别。
6. 前五章每章增加5点时髦度，终章加20点。以后每周二、四、六可在事务所与穿强化服的玛琪艾儿再战。

## 实测与移植细节

- 独立 X 新档从朝香镇出发。选呱呱泡蛙、在博士处领小火龙和 X 石，拿到超级环后回古香镇复活宝宝暴龙、在香殿取得居合斩，再去树果园种下橙橙果，用背包中的喷壶浇水。将小火龙练到36级进化，在正式野战完成超级喷火龙 X 变身，核对图鉴登记、战后恢复与携带物保留。
- 从实际打赢卡露妮的 X 存档，连续走过奇楠市、日晷和帅哥全部六章。胜出宅邸首场，确认增加 BP，核对最后的告别、事务所的人员变化和合计45点时髦度。另一段实走学了五种轮滑技巧，在白檀时装店用券购买头饰，再打赢冠军后的反转先生。从8号道路实地拾取心之鳞片，在风絮镇让甲贺忍蛙回忆暗袭要害并实际删除该招式。又分别从冠军档走到无名洞窟和终结洞窟，用商店购买的球捕获了 Lv.70 超梦与基格尔德，并核对到手的超梦进化石 X。
- 对战宅邸导入了1,072套原阵容、300名普通训练家和女仆长的队伍。867项专项回归核对各组阵容、兑换表、版本和时段门槛，实际打了普通单打。普通20胜、超级50胜、所有奖品、每个孵化组合和一周后的再生没有逐项从新档手动耗时走满。
- 朋友狩猎区原作使用3DS好友名片；本作随存档保存本地名片。历史配信的折价券和火稚鸡由白檀市本地配送员领取。服装店提供绿宝石小悠的头饰配色。轮滑用方向键和 B 键，空中动作按当前选择展示。对战城堡使用胜场晋爵。果圃支持浇水、肥料与突变，尚未复刻捕虫和除草过程。
- 卡洛斯场景有地形、剧情和道具自己的交互位置。部分可选人员和道具采用了转换后能站立、能靠近的交互格，和3DS画面中的精确站位会有差别。
