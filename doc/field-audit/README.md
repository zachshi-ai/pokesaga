# 从城都到伽勒尔的地图走查

在安卓标题画面选「继续游戏」可沿用旧档。想直接去某个地区，可以在背包里用地区转移器。各地的剧情门和场地移动条件仍然生效。

神奥主线的毁坏的世界包含在神奥的统计内，十层独立按《白金》的地图矩阵、机关和物件表重画。合众原版的海底遗迹、城都的狩猎地带、卡洛斯的水路都有跨地图专项，记录了在相邻场地之间连续移动的结果。[毁坏的世界](rift.md) · [卡洛斯原位入口和冲浪路线](kalos-coast.md) · [21 处人物出场与门槛](ds-door-staff.tsv)

走查以当前游戏登记的城镇、道路、房间和设施实例为单位。每张地图分别加载，使用游戏的移动和碰撞逻辑记录步数、出口与缺口；存档、剧情前后、机关、冲浪、柜台等则另走连续路线。心金的数据含 22 个过场或未使用的地图头，表内保留了无法自由行走的状态。版本差异共用地图时，按各地区表中的版别和剧情状态说明计数。

神奥和合众的大批室内按可见地板收紧镜头。三维原作中的视角转动、叠层和连续旷野，按绿宝石式四向移动改绘。阿罗拉缺少部分究极版房间的原模型；合众的原作逐图比对使用《黑》和《黑2》。当前游戏内关都、丰缘剧情分别使用火红叶绿、绿宝石，没有单独登记《Let's Go》和《欧米伽红宝石／阿尔法蓝宝石》两套世界。

《Ｘ》另从启动页建立新档，在朝香镇选择寄存，到名水镇领御三家后，实走 68,450 步完成八个道馆、闪焰队、联盟、卡露妮和庆典。最后回到小悠房间，存档中保有八枚卡洛斯徽章及名人堂记录。

## 安卓版复测

4.68.0-study 的 ARM64 安装包使用版本号 101。下列结果取自签名 APK 中提取的游戏资源，SHA-256 为 `21d286c496716d28fb097fcf0b46c5055aaf8fe48845bc69a2a2d7de98ac326a`。

- 神奥从枪之柱的剧情存档出发，进入毁坏的世界，连续走 750 步完成赤日和骑拉帝纳的剧情，再回到送别之泉。另从地下三层的旧档走过后半段，计 617 步。
- 卡洛斯读取上述新档的第八枚徽章检查点，再走 17,120 步通过徽章检验、冠军之路和联盟，击败卡露妮并回到家。
- 伽勒尔的 222 张地图及 5 个额外状态共走 8,711 步，核过 593 个出口。单独操作对战塔的单打和双打、酒店调查、三间对战咖啡馆、极巨巢穴，以及五间服装店和四间沙龙。
