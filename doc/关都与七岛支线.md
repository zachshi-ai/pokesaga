# 关都与七岛支线

本作的关都与七岛沿用同一个存档。默认采用火红资料。玉虹公寓三楼的程序员可以切换三处交换条件、游戏角奖品和诞生岛代欧奇希斯的火红或叶绿版本。已完成的交换和捕获保留。玩家从真新镇带走皮卡丘，本作把这条开局对应到雷公。

| 地点 | 条件与玩法 |
| --- | --- |
| 真新镇、常磐市、华蓝市 | 得到图鉴后找奈奈美领取城镇地图。通关后她可以给伙伴梳毛，间隔五百步。常磐老人启用教学电视，可逐回合播放战斗、解毒、换人和捕捉胖丁四场教学，使用演示员的队伍与道具。有学习器后可学习设定快捷道具。华蓝桥前战胜宿敌获得名人传言器。 |
| 关都城镇、道路与七岛 | 名人传言器分别记录十六人的六条传闻。访问原作的路牌、杂志和居民，完成对应剧情后再回访，会出现新内容。收齐一人的六条后可阅读他或她的留言。八人的金黄训练家爱好者俱乐部会随四天王与通信对战成绩改变支持者。 |
| 月见山、玉虹公寓、金黄格斗道场、五岛水之迷宫 | 售卖五级鲤鱼王；可拾取二十五级伊布。五名格斗训练家使用原版队伍，击败师父后从飞腿郎和快拳郎中二选一。水之迷宫的饲育家要求首位伙伴亲密度满、队伍有空位，交付波克比蛋。 |
| 游戏内交换、招式导师与博士助手 | 九处赠换沿用原作要求的种类、交付种类、昵称、原训练家和携带物。十四位常规导师及模仿少女检查原作可学名单，学成后消耗该次机会。二岛回忆招式用两枚小蘑菇或一枚大蘑菇。助手分别在登记捕获 20、30、40、50 种关都宝可梦时发放不变之石、探宝器、护符金币、学习装置。 |
| 玉虹百货、游戏厅、纪念之柱 | 屋顶购买三种饮料，女孩分别交换 TM16、TM20、TM33。柠檬汁还可在五岛纪念之柱供奉，获得 TM42。在餐厅领代币盒后可买代币、停转三只转轮、兑换宝可梦、学习器或道具。 |
| 玉虹公寓三楼开发室 | 设计师检查关都图鉴 001 至 150 号并展示证书。完成第三世代全国图鉴的 380 个指定编号后可展示全国版证书。两张证书使用原版图块与边框。 |
| 浅红沙湖乐园 | 门票 500 元，每次 600 步、30 枚原野球。原野战使用原野球、诱饵、石头与离开四种操作。球耗尽或步数用完返回入口，捕获进入队伍或箱子。 |
| 静态及游走遭遇 | 发电厂的两只顽皮雷弹、急冻鸟、闪电鸟、火焰鸟均位于原地图。七岛网络修复后，游走的传说宝可梦在关都道路间移动，受伤或带异常逃走后再遇仍保留状态。在配送员领取船票后可去肚脐岩挑战凤王和洛奇亚，去诞生岛完成三角石步数谜题，捕获攻击形态代欧奇希斯。 |
| 三岛与七岛遗迹 | 全国图鉴解锁前，三岛矿工仍在墙边；之后通道按挖通版原图打开，矿工赠送金珠。七岛必须以怪力把七个石头推进指定石盘。解锁后，七间遗迹各按本室的原版权重出现不同未知图腾，合计 28 种。 |
| 两岛游戏角、通信柜台 | 交付陨石并接回迷失妹后开放跳绳和嘟嘟利摘树果。可与工作人员本机练习，或同一 Wi-Fi 创建、加入房间。共同跳绳按同步人数加分。摘树果分左右中三列，邻列能由队友一起啄取。两名真人时补一只 NPC 嘟嘟利。成绩在店内记录，达到门槛发放树果。宝可梦中心二楼的直接通信柜台提供各派一只的通信单打，真实胜方计入四岛贴纸。 |
| 训练家之塔、四岛、六岛 | 七岛训练家之塔有单打、双打、三连战和混合四组，每组八层，按玩家最高等级匹配。顶楼领取各组首次奖品并记录时间。四岛可依联盟登记、孵蛋和通信胜场升级贴纸，科拿家的玩偶随联盟登记 25 至 200 次逐步增加。鲤鱼王和赫拉克罗斯可在各自的测量地点挑战纪录。 |

### 如何核验

从新档行走的关都至七岛旅程由 `tools/test_kanto_journey.py` 驱动，经历八馆、联盟、登记 60 种、七岛取回双宝石以及读档。区域支线的 `tools/test_frlg_sidequests.gd` 从独立新档开始，将角色放到要测的场景，通过实际方向、A 键和菜单交互验证，覆盖收集、退场、重复领取、解谜、游走回写与存档。传入 `-- tower` 会从大厅实走四条赛道共 32 层，打完 52 场回合战斗，验证已清层重进、屋顶领奖和电梯回程。 `tools/test_frlg_wire.py` 为跳绳、摘树果和单打分别启动两个独立 Godot 进程，检查两端的成绩、胜负与奖励。

### 与原作的差异

训练家之塔使用原版 24 张楼层布局，按赛道切换地砖、碰撞、出战者和位置。混合赛按原版顺序使用三种布局。玉虹转轮使用火红的卷带、连线和奖励，停轮采用本机触屏节奏；原作机器的后台控奖算法未移植。教学电视从原作读取四场的队伍、等级、招式与操作序列，在本作战斗系统中播放。演播室主持人的走动和进出场镜头尚未逐帧还原。游戏角使用本作的局域网协议，已验证本机双进程，三至五台实体安卓手机同场尚未实测。原版外设、跨卡交换、锦标赛和活动配信的全部组合仍需分别验证。

原版地点、文本依据和两岛玩法可在 [FireRed 地图脚本](https://github.com/pret/pokefirered/tree/master/data/maps)、[名人传言器](https://github.com/pret/pokefirered/blob/master/data/text/fame_checker.inc)、[宝可梦跳绳](https://github.com/pret/pokefirered/blob/master/src/pokemon_jump.c)、[嘟嘟利摘树果](https://github.com/pret/pokefirered/blob/master/src/dodrio_berry_picking.c) 对照。
