# 从草路镇到冠军与赛后

《剑》和《盾》沿用首次到达时选择的版本。小悠拿到草之徽章后，从草路镇向东走５号道路。先在桥头解救医生、领取洛托姆自行车，再挑战赫普。带来的队伍可以参加大部分战斗，开门、赛事登记和馆主出场仍看这份存档在伽勒尔的进度。

| 地点 | 主要操作 |
| --- | --- |
| 水舟镇 | 先见到洛兹，再去灯塔找露璃娜。进场后用三个颜色的水阀改变水幕。 |
| 机擎市 | 经过第二矿山、旅馆的玛俐剧情后回竞技场。对野生宝可梦，击倒和捕获的计分不同。 |
| 溯传镇 | 《剑》挑战彩豆，《盾》挑战欧尼奥。操纵旋转座椅穿过场地，留意推动方向。 |
| 舞姿镇 | 对战中回答问题，答案会影响场上的能力。 |
| 战竞镇 | 《剑》是玛瓜，《盾》是美蓉。用探测器找陷阱。９号道路救医生升级自行车，骑车穿过战竞湾。 |
| 尖钉镇、拳关市 | 经街巷挑战聂梓。奇巴纳的道馆用天气双打，带上两只可以出场的伙伴。 |
| 宫门市 | 冠军杯、洛兹大厦、决赛、闇夜与塔顶无极巨化团战按事件顺序开启。击败丹帝会把上场队伍登记进伽勒尔名人堂。 |
| 微寐森林 | 通关后调查英雄石台，与王族兄弟交手、平息各馆暴走。在塔顶收服本版传说宝可梦，最后回森林与赫普对战。 |

## 铠岛

在马士德武馆见师傅，去湿原找回三套修行服，在热身洞穴采菇，再和本版对手竞争秘传铠甲。《剑》遇见克拉拉，《盾》遇见赛宝利。蜜叶还会让你从能超极巨化的妙蛙种子和杰尼龟里任选其一。

拿到熊徒弟后，把它带在队里去看风景。回武馆选择恶之塔或水之塔，逐层对战，读卷轴决定进化流派。打完微寐森林的赛后赫普战，再回武馆见赫普，循蜂群找极巨甜蜜蜜。武道熊师的汤需要三朵极巨菇菇和一份极巨甜蜜蜜。普通极巨汤由武馆的汤师傅制作，针对选中的队员生效。

## 王冠雪原

在滑溜坡找皮欧尼和夏科娅。极巨大冒险使用租借伙伴，途中可以选岔路、交换刚击败的宝可梦。回冻凝村领取笔记，三条调查线可以交错进行。

- 丰饶之王。修好雕像，用八块极矿石换种子。雪田和古墓的田地二选一，保卫村子、编好缰绳。成为冠军后可以在王冠神殿收服骑着爱马的蕾冠王，缰绳可用来分离、重新合体。
- 遗迹巨人。在钢铁遗迹吹口哨，在岩山遗迹让队首携带不变之石，在冰山遗迹让几何雪花领队。捕获三只后全部带到抉择遗迹，按石壁的纹样点亮石灯。本存档可以选择一位新的巨人。
- 传说的鸟。调查球湖大树。急冻鸟留在王冠雪原，闪电鸟去了伽勒尔旷野，火焰鸟去了铠岛。三只均使用伽勒尔形态，捕获才完成笔记。

三条笔记完成后回村交报告，可以再到巢穴调查异界气场。打完赫普、马士德并交齐雪原报告后，到宫门竞技场找丹帝，挑选搭档参加三轮双打明星赛。
