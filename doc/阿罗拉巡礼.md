# 阿罗拉巡礼与冠军卫冕

在同一个游戏中使用「地区转移器」，选择阿罗拉。第一次到访时选一个版本，并决定携原队出发，还是把现有伙伴寄存到共享电脑。之后回来沿用本档的版本和剧情进度。队伍上限仍为十二只，电脑、背包、图鉴、其他地区的印章和冠军队伍共用。首站是美乐美乐岛小悠家的卧室，下楼与妈妈交谈。

在美乐美乐岛自己的卧室打开 **START → 工具 → 阿罗拉版本**，可以在这份存档中体验其余三个版本。首次进入新版本仍会让你选带队或寄存。返回之前玩过的版本，已完成的试炼、拿过的剧情道具、收集点和冠军记录会恢复。队伍、电脑、图鉴和资金随小悠同行。

## 沿途该找谁

1. **美乐美乐岛。** 莉莉艾在吊桥找小星云，哈拉借走光辉石，在祭典归还打磨好的手环。到研究所见库库伊和洛托姆，去学校领取学习装置。三名学生可按任意顺序挑战，球场的约瑟夫在三人落败后接受对战，老师随后登场。去好奥乐港对付骷髅队并挑战伊利马，再去葱郁洞窟搜索三个巢穴。完成考验后，库库伊把带着一般Ｚ的岩狗狗借给小悠示范。打开招式页的「特殊行动」，选择「Z 招式」里的撞击。找回小星云后，回利利小镇挑战哈拉。
2. **阿卡拉岛。** 抵达慷待市后遇丽姿、玛奥及从卡洛斯来的德克希欧或吉娜。欧哈纳镇找哈乌，牧场找玛奥，５号道路遇格拉吉欧。水莲借出拉普拉斯调查涟漪；在皇家巨蛋可实际选择招式和目标，四名训练家的表演赛随第一只宝可梦失去战斗能力结束。再完成卡奇的舞蹈与玛奥的料理，听芭内特博士解释究极之洞，在生命遗迹挑战丽姿。之后才会得到扎奥博去以太乐园的邀请。
3. **乌拉乌拉岛。** 在以太保护区遇见虚吾伊德，到马利埃静市见哈乌、库库伊，再上辉克拉尼山。天文台考验后古兹马出现在庭园。到以太之家找阿塞萝拉，在超市旧址依次拍到鬼斯、鬼斯通、耿鬼，才会进入后屋迎战谜拟丘。布尔美丽随后向魄镇发出挑战；解决镇内暗号、击败古兹马后回以太之家。莉莉艾被带走，格拉吉欧、哈乌移到码头，默丹在这里主持大考验。
4. **以太乐园与波尼岛。** 再访乐园时，哈乌在地下研究所Ｂ协助双打；正门守卫由格拉吉欧协助，下一战由哈乌联手对付扎奥博与职员。拿到门卡才能去宅邸找古兹马和露莎米奈。格拉吉欧在码头托付大师球和一支笛，莉莉艾换上旅装启程。到彼岸遗迹见证哈普乌成为岛屿女王，再到椰蛋树岛取得另一支笛。通过峡谷试炼，和莉莉艾在本版本祭坛合奏。之后按上表分别前往究极深海或究极大都会。
5. **究极版的花瓣。** 出发点与终点都是海洋居民之村的茉莉家。依次去好奥乐墓园、树荫丛林、维拉火山、辉克拉尼天文台、以太之家。究极之日在丛林挑战玛奥，究极之月挑战水莲。回茉莉家制成虹色之花，再战霸主。调查队送的毒贝比可以先不带走，之后返回大都会再领。
6. **拉纳基拉山与联盟。** 去山脚与格拉吉欧对战。《太阳／月亮》上山还会遇到哈乌。四天王可任选顺序，离开联盟或全队战败会清除本轮战果。冠军房核对的是阿罗拉本轮四位天王的胜利。小悠回家后，首次冠军队伍与原有地区记录一起保留。

巡礼要求调查、对话或对战的地方，以该版本本地事件为条件。即使从其他地区带着高等级伙伴抵达，船坞、巢穴、研究区、祭坛与冠军房仍按这些条件开放。同一只宝可梦的形态继续使用同一个图鉴编号，遇见或收服的个体形态才会被记录。

## 关键道具与用法

| 道具 | 取得与使用 |
| --- | --- |
| Ｚ手环／Ｚ强力手环、属性Ｚ纯晶 | 祭典拿手环，考验与大考验拿相应纯晶。进入队伍详情，给会对应属性招式的伙伴携带纯晶，再在战斗的「特殊行动」选Ｚ招式。每场对战己方可以使用一次。专属纯晶还会核对物种、形态和基础招式 |
| 骑行装置、垂钓竿 | 哈拉大考验后登记肯泰罗。巡礼再认识长毛狗、拉普拉斯、喷火龙、重泥挽马、巨牙鲨、怪力。潺潺之丘试炼通过后得到钓竿。携带旧队的秘传招式不会替代本地骑乘授权 |
| 学习装置 | 学校领取，默认启用。本地战斗会让后排伙伴也获得经验，从背包可切换开关 |
| 太阳之笛、月亮之笛 | 以太乐园脱险后随船获得一支，另一支来自椰蛋树岛，在对应祭坛与莉莉艾合奏 |
| 奈克洛索尔合体器、奈克洛露奈合体器 | 究极版在拉纳基拉山收服奈克洛兹玛后由阿克罗玛交付。到马哈罗山路找莉莉艾，可收服本版本的小星云。把奈克洛兹玛和相应封面伙伴放在队中，从背包使用对应仪器，选择个体合体。再次使用可分开，队中要预留一个空位。融合伙伴的等级、招式和闪光状态随个体一并保存 |
| 究极奈克洛Ｚ | 在拉纳基拉山收服奈克洛兹玛后取得。由合体形态携带，可从战斗的特殊行动选究极爆发 |

## 冠军卫冕

通关告别剧情后回联盟大厅找向导。四位天王换用重战队伍，重新登记本轮四场胜利，冠军席才会迎来挑战者。第一次卫冕固定对哈乌。此后每月１日，太阳／月亮由扎奥博挑战，究极之日／究极之月由露莎米奈挑战。其他日期从本版本的候选人中抽取。马睿因能在日月挑战冠军，究极版的对应席位是古兹马。究极版的格拉吉欧在彩虹火箭队事件结束满三十天后进入候选。

赢下卫冕会增加本档的卫冕次数，保留挑战者姓名并回到家。初次登顶的名人堂队伍、四岛印章、剧情结局与跨区进度继续保留。中途离开或战败后，可以重新向大厅向导登记。
