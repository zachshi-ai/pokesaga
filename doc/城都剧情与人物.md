# 从若叶镇到白银山

在同一存档中首次前往城都，会从若叶镇开始当地剧情。下面按《水晶》的事件顺序列出容易找不到人的地方。道馆可以按剧情允许的顺序挑战，浅葱和湛蓝之间需要往返一次。

|进度|去哪里找谁|推进后的变化|
|---|---|---|
|第一次出门|先在家一楼找妈妈，再在空木研究所选菊草叶、火球鼠或小锯鳄。到30号道路的宝可梦爷爷家。|大木交给你图鉴后离开。回程在吉花市遇到红发少年，回研究所交还神奇的蛋，再找助手领精灵球。|
|桔梗市、桧皮镇|上喇叭芽之塔找长老，打败阿速后去桔梗市的友好商店找空木的助手。到桧皮找钢铁，他会前往呆呆兽之井。|井底击退火箭队后，钢铁回家，呆呆兽回到镇上，道馆开放。往西会遇到阿银。|
|栎树林、满金市|帮学徒把大葱鸭从树林赶回师傅身边，学会居合斩。打败小茜后，先听旁边训练家的话，再找小茜领标准徽章。|在36号道路和花店妹妹交谈，再回满金花店向姐姐借杰尼龟喷壶。移开胡说树，才能继续向圆朱前进。|
|圆朱、浅葱、湛蓝|到烧焦塔找阿银，去地下查看三只传说宝可梦。到舞场挑战五名舞伎，再找绅士领冲浪。|三兽离开后松叶回道馆。阿蜜照顾灯塔顶层的电龙；去湛蓝药店取秘传药送回，阿蜜才返回浅葱道馆。打败阿四后，门外找他的妻子领飞翔。|
|愤怒之湖、卡吉镇|与红色暴鲤龙战斗，再和岸边的阿渡说话。跟他到卡吉镇商店，进入火箭队基地。|找到两句口令，跟随黑暗鸦，关停三只顽皮雷弹供电的信号装置。阿渡给潮旋，卡吉道馆可以挑战。|
|满金广播塔|七枚徽章并清除基地后，去广播塔五楼查假局长。拿地下钥匙，到满金地下通道迎战阿银，按顺序操作机关。|地下仓库的真局长给钥匙卡。回塔打开三楼隔板、击退干部后，火箭队撤离，恢复广播，局长给透明铃铛。|
|烟墨市、龙穴|从冰雪通路拿攀瀑。打败小椿后去龙穴，用潮旋进入龙祠回答长老的问题。|小椿在龙祠承认胜负并给升龙徽章。途中再找她领龙息，返回龙祠可领迷你龙。八徽章后空木在若叶镇给大师球。|
|石英高原联盟|从若叶镇向东，跨都城瀑布和冠军之路。阿银在冠军之路出现。依次击败一树、阿桔、希巴、梨花和阿渡。|胡桃和大木到场，阿渡带你进入名人堂。回到若叶镇后，再向空木领取水流号船票。|
|水流号、发电厂、华蓝|从浅葱登船，帮值班水手找同事，找到船长室里的小女孩，再到枯叶下船。发电厂报案后，到华蓝道馆和24号道路追火箭队员。|从华蓝道馆水池找回零件交厂长，到25号道路遇见小霞之后，她才回华蓝道馆。到紫苑收扩充卡，可用收音机叫醒枯叶的卡比兽。|
|常磐道馆、白银山|去红莲岛找青绿，回常磐挑战他。集齐两地共16枚徽章后，到真新镇找大木。|大木开放白银山并给城都秘传学习器 08。教会队友「攀岩」，对准岩壁按 A 登顶。打赢赤红后他离开，队伍回到若叶镇。|

冠军后另可去月见山找阿银。赢下这一战后，他会在手机本地时间周一、周三出现在石英高原的联盟入口，每个约战日可赢一次。

物品的领取人、所需徽章、背包和场外用法另列在[城都特殊道具与场外招式](城都特殊道具.md)。原作版本差异以[《金／银》地图脚本](https://github.com/pret/pokegold/tree/2bbfba60051acfbed96d68fb5e40173a06df67d8/maps)及[《水晶》地图脚本](https://github.com/pret/pokecrystal/tree/9ce4c4e5068ffdf56e23ca3d8dc9178b2465d482/maps)为对照。
