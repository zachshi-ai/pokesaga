# 进化道具从哪里拿

任何营业中的商店都能打开「进化材料产地」。价格按钮可以直接购买，标着地区名的材料要去相应地区找补给商。表中的城镇是一个能买到的地点，同地区其他营业中的商店也有相同货物。每种材料都可以重复购买。每个野外拾取点可免费领取一次。下表坐标按本作地图的（横格，纵格）记，从左上角开始。标有「隐藏」的地点没有道具球，走到旁边，面向该格按 A。

从「背包 → 进化道具」选道具再选宝可梦，或从「队伍 → 队员 → 道具进化」选择材料。每次成功进化消耗一个。学习版把交换、携带升级等道具操作统一为直接使用。觉醒之石按个体性别判断，可以在队员名字旁查看。浑圆之石可以直接给小福蛋使用。

## 其他形态道具

- 18 种太晶碎块都在商店的「太晶」货架。新游戏另有火、水、妖精各一块。在队伍界面选择太晶属性会消耗一块。
- 洛托姆家电、阿尔宙斯石板、盖诺赛克特卡带与其他形态专用道具，可在设有形态研究员的宝可梦中心免费重复领取。打开队伍，给对应宝可梦携带即可切换。
- Mega 进化、超极巨化、Z 招式和战斗中的太晶化沿用本学习版的战斗按钮。开启这些按钮无需购买强化道具。

商店的「战斗道具」货架可补购力量强化、防御强化、特攻强化、速度强化、命中强化、要害攻击与能力防守。野生战和训练家战都可以打开「背包」，在我方行动时使用一个。能力防守保护全队五回合，换人后仍然有效。其他六种强化仅对当前上场的队员生效。

强制锻炼器累计的基础点数依照被击败物种的奖励计算。每项上限为 252，总上限为 510。安抚之铃增加升级时获得的亲密度，影响报恩和迁怒的威力。物种奖励与初始亲密度采用项目锁定版本的 [PokeAPI 数据](https://github.com/PokeAPI/pokeapi/tree/193d8d4fbb57cf962e3f7c1ce5299a6fe847b3f8/data/v2/csv)。
