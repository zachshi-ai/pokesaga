# 合众两段旅程

首次前往合众，在 **START → 背包 → 重要道具 → 地区转移器** 中选合众。从鹿子镇小悠的卧室拆开红豆杉博士送来的礼物。带着外区冠军队来，也需要选择本地搭档、完成初次对战，再逐个打开道路和道馆。满队时，电脑仍能保留或安置伙伴。

| 阶段 | 旅程 |
| --- | --- |
| 两年前 | 鹿子镇、唐草镇演说、三曜道馆、梦的遗址、七宝博物馆、矢车森林、飞云、雷文、冷冻仓库、帆巴、电气石洞穴、吹寄、雪花、龙螺旋之塔、古代城、双龙、冠军之路和联盟。四天王之后在 N 的城堡唤醒莱希拉姆，面对 N 和魁奇思。 |
| 前篇通关后 | 可以继续解决贤者事件，再次挑战四天王，与阿戴克争夺冠军。准备好后在鹿子镇自己家的一楼找妈妈，决定是否开始两年后的生活。 |
| 两年后 | 从桧扇市瞭望台领取搭档，经过算木牧场、黑连的道馆、立涌道馆和宝可坞。亚堤、小菊儿、菊老大之后有世界锦标赛和等离子驱逐舰。继而挑战风露、夏卡、西子伊，从巨人洞窟的暗黑酋雷姆和魁奇思一路走到联盟，在冠军房挑战艾莉丝。 |
| 后篇通关后 | 在桧扇市的家打开 START 的工具菜单，用「回忆链接」重访鹿子镇，回来时仍能接着艾莉丝之后的进度。 |

两段共享钱、图鉴、队伍、电脑与个体数据。小悠的外观贯穿全程。两段分别保存徽章、剧情道具使用许可、NPC 的出场条件和最近回复地点。转移器可随时回到当前年代的城镇入口，飞翔只列出本段已经到访的城镇。合众地区地图也随年代更新，例如桧扇市与海底隧道会在后篇出现。

## 可以去哪里做支线

| 地点或人物 | 实际玩法 |
| --- | --- |
| 七宝博物馆、古代城、自由庭园、P2 实验室 | 复活化石、选择化石、持船票搭船去见比克提尼，或带盖诺赛克特去找研究员。历史活动票在本学习版内发放。 |
| 3 号道路培育屋 | 寄养相容的伙伴，走路后回来取蛋、孵化。电脑与培育屋保存各自寄存的个体。 |
| 雷文市 | 进入音乐剧、对战地铁，或在后篇拾到遗忘物，跟进琉璃的通讯和交换。 |
| 帆巴市、山路镇等地 | 把拾得的碎片交给对应颜色的招式教学者，选到符合条件的队员才会扣碎片。 |
| N 的城堡、龙螺旋之塔和巨人洞窟 | 后篇通关后可以追踪 N 的龙和酋雷姆，取得基因之楔，进行合体或解除合体。 |
| 路旁的隐藏洞穴 | 后篇有 20 个入口。可进出洞穴，遇见住民或捡取物品，离开后会回原来的那条路。 |
| 宝可坞、加盟大道、世界锦标赛、黑色摩天楼 | 拍摄影片、经营商铺或参加三轮淘汰赛。锦标赛可租借队伍、与对手临时交换队员，或挑战 17 类属性专家。摩天楼有守门训练家、区域首领和十区挑战。 |

合众商店按本时代的徽章数增加货架，每个柜员有自己的商品。地上可见和隐藏的拾取点按事件记录，领取后不会因进屋、切换年代或读档而重复出现。秘传学习器可以从背包实际教学。桥影、水纹、晃动的草和洞窟尘土使用脚下的地形与当季的遇敌表。

## 原版对照范围

地图从两个版本各自的区域、地形、坐标、门、房间与机关记录换算成 GBA 四向场地。外景使用《绿宝石》风格的地形和建筑，部分室内、道馆和冠军房使用原房间模型重绘。草地、桥面、水和台阶分别读取碰撞与通行条件。支线对话是中文改写。音乐剧改成触屏演出，加盟大道使用本地访客，摩天楼采用十区挑战。DS 联机、梦境世界服务、所有原版奖牌和每日居民事件仍有差异。

地图、角色位置、柜员商品、遭遇、正常难度的对手队伍及野外事件数据可对照两个源项目。宝可梦、道具和招式的中文名参考 PokéAPI 数据。游戏直接使用仓库里已转换的资源。[Pokémon Black](https://github.com/squiddonaut/pokeblack) · [Pokémon Black 2](https://github.com/fuddlesworth/pokebw2) · [PokéAPI](https://github.com/PokeAPI/pokeapi) · [《绿宝石》图块与主角参考](https://github.com/pret/pokeemerald)


## 本地回放

在项目根目录运行以下命令。需要 Godot、Python、NumPy 和 SciPy。驱动会新建独立存档，用走路、交谈、训练、战斗、教学和存读档推进剧情。最后从 START 实际使用回忆链接，检查两个年代之间往返后的队伍和电脑。

```sh
python3 tools/test_unova_journey.py --godot godot --with-alder --verify-memory --result-save /tmp/unova-champion.json
```

要验证进入后篇时把队伍寄存，另起一次并加上 `--transfer boxed`。支线、地区转移和对战设施的定向回归分别从 `tools/test_unova_side.gd`、`tools/test_unova_entry.gd` 和 `tools/test_unova_pwt.gd` 启动。

### 4.59 的验证记录

- 用标题页创建的存档，沿原道路选御三家、训练、打道馆和联盟。两年前打完 N 和魁奇思；在同一存档从桧扇市重新出发，打过暗黑酋雷姆、魁奇思、四天王与艾莉丝。另一次读入神奥名人堂的 12 只旧队，走完两代后再核对两份徽章与神奥记录。
- 后篇寄存路线用当地伙伴出发。在 5 号路，三只队员中一只倒下时，查尔斯拒绝开始轮盘对战。回雷文市治疗后带三只健康伙伴返回，赢下查尔斯，之后打过联盟与艾莉丝。通关后回读箱子核对寄存队员。
- 驱逐舰上逐一踩过四个开关，持卡返回甲板。后篇冠军之路实际推动两处石头、填平岩坑。土坡测试逐个走了 857 处单向跳点。
- 通关档从桧扇市家里的回忆链接回到前篇，经双龙市、11 号路、村庄桥、12 号路、笼目镇走到 13 号路。分批交还长翅鸥的三封信后领取 TM89，回 3 号路捕获 Lv.8 豆豆鸽，让它学会急速折返，读档核对招式和学习器。
- 从同一通关档飞到帆巴市，步行到锦标赛柜台报名混合单打，每轮实际交换一只宝可梦，打赢三轮。重新读档后为 1 冠、1 BP。另做 276 项道具与支线检查、155 项锦标赛检查。这些定向用例会单独设置所需剧情条件。
- 安卓模拟器用触屏操作启动页、背包和地区转移器，并从真实进度进入 N 与艾莉丝的剧情和战斗。完整长程回放在 Godot 里加载签名 APK 中的游戏资源，使用正常玩法输入自动执行。带队路线在挑战阿戴克后接着打赢艾莉丝，共 83,250 步、5,102 个战斗回合。安装包内的资源另外通过了 55 组回归，包括旧地区流程、图鉴、队伍、地区转移和世界地图。
