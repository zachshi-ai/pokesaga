# 素材重建

Godot 平时读取已生成的剧情、声音和图集。修改地图的通道、角色对白或战斗队伍时，使用 `content/regions/<地区>/maps/` 中正在发行的文件。只想重画图像时，工具会保留这些手工调整。

## 选择上游与生成环节

Python 3.9+ 需要 Pillow、NumPy、FontTools；单独刷新地图人物还需要 requests。图鉴贴图宏展开需要系统 C 预处理器 `cc`，重新合成音频需要带 Vorbis 编码器的 FFmpeg。以下命令在仓库根目录执行。

```bash
python3 -m venv ../pokesaga-venv
source ../pokesaga-venv/bin/activate
python3 -m pip install Pillow numpy fonttools requests
python3 tools/fetch_sources.py
python3 tools/rebuild_assets.py all
```

上游仓库和提交固定在 [asset_sources.json](../tools/asset_sources.json)。默认输入目录为工程旁的 `pokesaga-sources/`，可用 `POKESAGA_SOURCES` 指向其他位置。各来源也支持独立覆盖，例如 `POKESAGA_CRYSTAL=/path/to/pokecrystal`。获取命令支持只写来源名，例如 `python3 tools/fetch_sources.py crystal firered`。生成可对另一份现有工程运行，例如 `python3 tools/rebuild_assets.py maps --project /path/to/copy`。

| 环节 | 素材与产物 |
| --- | --- |
| `maps` | pokecrystal 的 4×4 图块按显存区、逐图块配色、地区屋顶重画 377 张在用城都图，保留原始像素和游戏中的格宽。修复门点并从原事件更新中文告示与隐藏道具。pokefirered 提供草地属性和七岛海岸连接。再接入丰缘返程和世界路线。按最终碰撞、门点和地标生成各图的 ORAS 场景描述及全景图底图。 |
| `icons` | 从 pokeemerald-expansion 道具表读取图像和调色板，生成背包图集和中文索引。 |
| `dex` | 用固定 PokeAPI CSV 建立编号、形态、中文名和原型关系。按 pokeemerald-expansion 物种声明解析原色与异色调色板。PokeAPI/sprites 补充骑乘姿态和背面才能辨认的性别差异。本版收录 1,678 条形态展示数据。 |
| `font` | 从 Noto Sans CJK SC Regular 生成游戏中文子集。新增菜单或剧情用字后可重新运行。用系统无关的字形绘制“图鉴”“悖谬”等标题。 |
| `audio` | 从 13 首 MIDI 曲谱合成 BGM，另生成 16 个音效。发行素材保留原有 BGM 编码；FFmpeg 优先使用 libvorbis，本机只有内置 Vorbis 时用双声道编码，相同输入在同一套工具下可以重复生成。 |

原始城都转换器 `tools/gen_johto.py` 还会产出上游未采用的房间，并重新生成地区数据。做原始导入实验时，把 `POKESAGA_PROJECT` 指向实验工程。学习版在已有可编辑地图上运行 `maps`，保留关都故事、道馆战斗和渡轮等设计。已有 HD 立绘来自 PokeAPI official-artwork。若要单独重建这批 128×128 立绘，运行 `tools/fetch_artwork.py`。

## 始源蓝宝石地图与角色

游戏从通行数据读取地面、碰撞、楼梯、城镇和走道。世界地图中的海岸、跨地区地理与后世代城市是本作的组合设计。丰缘页的「丰缘原画」单独展示 ORAS 的正式地区插画。[原画图录](https://archives.bulbagarden.net/wiki/File:Hoenn_ORAS.png)

| 内容 | 生成方法与输入 |
| --- | --- |
| 场景 | 运行 `python3 tools/import_oras_field.py` 导入固定的 111 号道路地形、宝可梦中心模型和有校验和的地点画面。`python3 tools/bake_oras_maps.py` 将地图碰撞、门牌及家具坐标编成 Godot 的分块场景。见 [场景素材清单](../tools/oras_field_sources.json)。 |
| 地区 | 编辑 `tools/world/regions.txt` 中的城镇、道路和地标，然后依次运行 `python3 tools/build_world_routes.py`、`python3 tools/world/render_charts.py`、`python3 tools/bake_oras_maps.py`。领航落点、地图索引和实际通行使用同一次生成的记录。 |
| 主角与墙图原画 | `python3 tools/world/import_atlas_art.py` 从固定版本模型渲染祐树的九帧动作，装入丰缘插画。模型提取者为 Random Talking Bush。已持有源文件时，可直接用 `python3 tools/world/render_brendan.py /path/to/BrendanOW`。[输入及 SHA-256](../tools/world/chart_actor_sources.json) |
| NPC | `python3 tools/oras_npcs/import_models.py` 将公开角色模型渲染图按脚底、身高生成透明图片。49 款立像全部采用 ORAS 角色来源。领航员使用哈奇老人；大木、关都八位馆主、火箭队和研究员共 12 款按项目角色装束改绘，改色规则与原始输入均可复现。[角色来源](../tools/oras_npcs/sources.json) |
| 宝可梦 | `python3 tools/import_oras_pokemon.py --sprites /path/to/PokeAPI-sprites` 按图鉴物种与形态键匹配 ORAS、Pokémon HOME 的现有图像。普通色与异色、正面与背面分别索引。无匹配的特殊造型沿用该造型的独立美术。星星、方块、太晶和极巨叠加独立渲染。[上游固定版本](https://github.com/PokeAPI/sprites/tree/c0542f7c51215d9672439012838c99f520596cbd/sprites/pokemon/versions/generation-vi/omega-ruby-alpha-sapphire) |
| 战斗场地 | 草甸、林地、城市、洞窟和冰洞采用 Showdown 整理的第六世代背景。沙漠、海面、天空之柱及联盟场地采用对应的丰缘背景。[来源与校验值](../tools/world/battle_sources.json) |

## 界面画稿

队伍与背包的草地、远山与旅行包背景由 ImageGen 生成，发布文件是 `assets/ui/field/meadow.webp`。替换它即可更换两页背景。对应生成提示如下。

> Create a production game UI asset for a polished retro handheld monster-collecting RPG: a panoramic landscape illustration, 3:2 wide, flat cel-colored pixel art like a meticulously composed 32-bit Japanese RPG background. A pale mint-green sunlit meadow with a winding cream path, tiers of distant teal mountains, tiny wild flowers and clustered pine silhouettes. At far right a single compact red-orange trainer's field satchel with a cream flap, green bedroll and brass buckle set on a flat rock, beautifully readable. Keep the left two-thirds open and somewhat lighter. Tactile fine pixel clusters, dark petrol outlines in foreground, lush restricted palette of eucalyptus, butter yellow, ivory and persimmon color accents. This is a clean uninterrupted background plate for the party/bag/dex interface, no people, no animals, no characters, no typography or marks, no UI, no logo, no border, no framing. Landscape edge to edge. It must feel like a real game art director drew it. Pixelated hard edges with careful art direction and atmospheric depth.

主要来源见 [pokecrystal](https://github.com/pret/pokecrystal)、[pokefirered](https://github.com/pret/pokefirered)、[pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion)、[PokeAPI 数据](https://github.com/PokeAPI/pokeapi)、[PokeAPI 图像](https://github.com/PokeAPI/sprites) 与 [Noto CJK](https://github.com/notofonts/noto-cjk)。
