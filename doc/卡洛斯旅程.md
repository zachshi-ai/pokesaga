# 卡洛斯《X／Y》

卡洛斯章节从 4.60 开始提供。点「继续冒险」，用背包里的地区转移器选卡洛斯。从别的地区走跨区道路抵达，首次到访也会触发同一段开局。标题的「新的冒险」会从关都新建存档。

## 第一次到朝香镇

先决定是否寄存当前队伍，再选《X》或《Y》。寄存会按队伍顺序把伙伴送进共享电脑空位，电脑空间不足时可以返回或改选带队。版本选择会写进这份存档。再次进卡洛斯会接着当地进度。开局还没照镜子就离开，回来仍会到自己的卧室。换好衣服后，用转移器回来会到朝香镇的领航员旁。其他地区的徽章、金钱、图鉴、个体和名人堂记录继续有效。卡洛斯本地的剧情、徽章和场地招式许可单独记录。

在二楼镜子前按 A，换好衣服下楼出门，到名水镇露天桌见四个朋友。提耶鲁诺让小悠先从哈力栗、火狐狸、呱呱泡蛙里选一个。多罗巴交给你图鉴，信要带回朝香镇给妈妈。第一次与莎娜对战时，派出的是在名水镇选的那只伙伴。

新版朝香镇到白檀森林入口的地图尺寸、商店位置和旧档落点见[卡洛斯地图](卡洛斯地图.md)。

## 八馆路线

| 行程 | 要做的事 |
| --- | --- |
| 朝香镇 → 名水镇 → 白檀市 | 领取第一只伙伴，交信，看捕捉示范。莎娜在白檀森林结伴，面向她按 A 可治疗。白檀市取得轮滑鞋，进道馆沿地下蛛网找到紫罗兰。姐姐三色堇会交给你学习装置。 |
| 密阿雷市 → 古木镇 → 遥香市 | 到布拉塔诺研究所对战、选择关都御三家和相应超级石。去巴尔法姆香殿帮忙找多丽米亚，拿笛子唤醒卡比兽。经古香镇和闪耀洞窟处理化石事件，再登遥香道馆挑战查克洛。 |
| 石香镇 → 镜穴 → 娑罗市 | 处理闪焰队拦路，去精练之塔见可可布尔和可尔妮。娑罗道馆先打四名轮滑手。第三徽章后上塔顶领取超级环，操作路卡利欧完成教学。战斗画面点「战斗 → 特殊行动 → Mega」，再点本回合要用的招式。 |
| 比翼市 → 13 号道路 → 密阿雷市 | 搭单轨电车，在比翼道馆找福爷。到 13 号道路取得发电厂通行证，击退闪焰队并恢复供电。棱镜塔分四层看剪影、选电梯并对战，最后由希特隆迎战。 |
| 香薰市 → 精灵球工厂 → 百刻市 | 通过传送房间挑战玛绣，去精灵球工厂与莎莉娜合力救人。经风絮镇和冰结洞窟解决暴雪王事件，再进百刻道馆挑战葛吉花。 |
| 弗拉达利研究所 → 石香镇秘密基地 | 从密阿雷的弗拉达利咖啡馆深入研究所，取得电梯钥匙，见 AZ，触发最终兵器升起。在基地解救本版传说宝可梦，《X》是哲尔尼亚斯，《Y》是伊裴尔塔尔。收服后可以换上队伍，并与使用超级暴鲤龙的弗拉达利再战。 |
| 连理镇 → 19 号道路 → 映雪市 | 在桥上分别与莎娜、提耶鲁诺和多罗巴对战，得到攀瀑。先到宝可梦村找到得抚，他回馆后再解开彩色冰台、取得冰山徽章。 |
| 冠军之路 → 光辉之间 → 庆典 | 守卫核验八枚卡洛斯徽章。四天王顺序自选，四人全部打赢后通往卡露妮。她最后派出持沙奈朵进化石的沙奈朵。登记名人堂，在密阿雷庆典迎战 AZ，之后回到朝香镇。 |

## 道具与队伍

- 秘传学习器需要先在当地取得，再教给能学的宝可梦。居合斩、怪力、冲浪、飞翔、攀瀑分别对应白檀、遥香、娑罗、比翼、映雪的徽章。外区带来的高等级队员、秘传招式和徽章仍要遵循这些条件。
- 超级石交给相应个体携带。训练家有钥石后，每场战斗双方各能超级进化一次。变身和招式在同一回合发生，战后个体恢复通常形态。图鉴登记实际见过或使用过的造型。多丽米亚可以到春日大道的美容院花 500 元修剪。时髦度会解锁更多式样，修剪后满五天或寄存电脑会恢复自然造型。
- 获取学习装置后，未上场且还能战斗的伙伴可以分到经验。可从背包关闭、再打开。队伍上限为 12，满员时礼物与捕获使用共享电脑或剧情换人。
- 欧斯先生在旅馆、宝可梦中心与道路关口教授 O 力量。在 START → 工具 → Ｏ力量 中选择对自己的效果，会消耗能量，使用多次后升级。集齐其余 16 种并将密阿雷时髦度升到 190 后，到南侧的内向咖啡馆找他领取孵蛋力。能量恢复使用游戏内步数代替掌机计步。
- 其余入口和奖励见[卡洛斯支线与道具](卡洛斯支线与道具.md)。

## 实测与改编范围

4.60 发行时，两条新档从标题开始，在关都实际领取伙伴并拿到灰色徽章，再分别走《X》寄存和《Y》带队。在桌面 Godot 载入签名 APK 内的游戏资源，通过普通移动、对话、道具、战斗和存档按钮走过八馆、分版捕获、四天王、冠军和 AZ。额外用一份 4.59 的神奥／合众冠军档带九只队员进入，填满十二格后用剧情换人，把哲尔尼亚斯放到首发，并在电脑里找到原先的帝王拿波。

当时还在安卓模拟器覆盖安装，实际点过地区转移器的队伍选择、名水镇的露天桌、路卡利欧的 Mega 按钮和光辉之间的卡露妮。

从这些档位的正式进度又实走了化石选择与复活、树果种植和浇水、超级喷火龙 X、奇楠对战宅第、百刻日晷升级、帅哥六章。一星餐厅三场双打、大酒店送餐／铺床／找失物、对战检验中心五轮，以及 13 号沙地和 21 号两种花田的野生遭遇也分别走过。所有学习器的取用条件、进化石时段和大量人物阶段另有定向用例。后者会设置剧情条件以便逐项检查。

卡洛斯将《X／Y》的建筑、地形与门连接投到固定俯视的 GBA 场地上，卧室、客厅、中心及部分街区用《绿宝石》图块重绘。角色沿用原作身份，玩家一直是小悠。NPC 与拾取物按可交互地标重新落点，对话采用中文重写。部分 3D 机关、原掌机动作、网上配信和朋友狩猎区采用本地操作；章节和道具的对应方式见支线说明。
