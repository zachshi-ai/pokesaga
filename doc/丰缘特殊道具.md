# 丰缘的道具与场外招式

同一存档可以保留外地队伍和背包。丰缘的场外秘传检查三个条件：在丰缘领过这台秘传学习器、持有对应丰缘徽章、当前队伍中有宝可梦学会这一招。学招可以早于拿徽章，学习器可以重复使用。全国编号 1 至 386 的宝可梦按《绿宝石》的秘传兼容表教学。[原作秘传兼容表](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/data/pokemon/tmhm_learnsets.h)

## 验证范围

- 新档主线实走经过八个道馆、两队基地、海底洞窟、天空之柱、双神事件、冠军之路和联盟。名人堂后的同一存档实际完成了借车换车、新紫堇断电并领取十万伏特、凯那至水静及水静至对战开拓区航程。弃船支线从船长室、潜水舱走进隐藏层，按 3、1、4、6、2 号房走完钥匙链，原路游出沉船，回凯那港用探测器换到深海之牙。
- 另外用独立场景验证了三种钓竿的授予、化石复原、方块混合与喂食、火山灰收集，以及跨地区徽章与秘传资格检查。两块化石前后收齐、全部玻璃哨兑换与战斗效果、每张钓鱼地图及游戏城全部奖品仍待逐项从头实走。
- 方块盒支持混合、喂食、入园和报名华丽大赛。粉末瓶可装入无线树果压榨获得的粉末并在柜台兑换物品。浅滩洞穴的工匠用四份海盐和四枚贝壳换贝壳之铃。限定船票和古老的海图可在当前学习版开启对应航班。

## 本版可玩的范围

从未白镇选伙伴、八座道馆、两队和烈空坐事件，到彩幽联盟战胜米可利、登记名人堂和回家领船票，已用同一个关都新存档走通。进入野生原野区需要能量方块盒；要提前离开，可在南区门口同服务员交谈。

戏法屋八间谜题、连胜家族、变化洞、流星瀑布大吾及对战宫殿的报名、比赛与退场均已接入。[三作支线入口与核验范围](三作支线.md)

绿岭市游戏角墙内的旧地下室入口在《绿宝石》原版中已停用。[绿岭市原版脚本](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/data/maps/MossdeepCity_GameCorner_1F/scripts.inc)
