# 丰缘支线与验收

## 从哪里开始

| 地点 | 触发与收尾 |
| --- | --- |
| 110号道路机关屋 | 每次先在门厅找出机关大王，再查看挂轴。八个房间依次用居合斩、踏板、连动闸门、怪力、五名问答机器人、转动隔板、彩色地板和冰面。每次找到卷轴，再开北边密码门领取奖励。最后在红蓝帐篷中选一顶。 |
| 111号道路连胜之家 | 在屋外向父亲挑战，连续打完父亲、母亲、女儿、祖母四场后进屋向母亲领取强制锻炼器。 |
| 109号道路海滨之家 | 打赢屋里的三名训练家后，店主送六瓶劲爽汽水，之后每瓶售价300元。每瓶能给一只伙伴回复60点体力。 |
| 凯那市市场、暮水镇 | 凯那市的女士给努力值合计510的首位伙伴颁发努力奖章，在队伍详情查看。暮水镇的同好会会长弟弟看首位伙伴的亲密度，高于等于150赠报恩，低于50赠迁怒。领过一份后等七天再来。 |
| 水静市宝可梦中心 | 训练家 ID 决定初见的是问答、收藏还是华丽大赛女士。问答女士从原作16道题抽题，答对送该题的奖品。玩家也能出题，交一件奖品，请身边的同伴答。在收藏女士处，同类五份或最喜欢的一件可换到对应奖品。华丽大赛女士按五种属性带不同宝可梦，累计五个合口味或五个不合口味的宝可方块后，家里电视会播出赛果。 |
| 水静百货一楼服务台 | 以原作商店回收价出售珍珠、星星沙子、星之碎片或金珠。奖励邮件可以在背包中写好交给队伍伙伴，到服务台读信或收回。 |
| 浅滩洞穴 | 根据设备本地小时显示高潮或低潮地图。在四个不同的潮滩上各采海盐、贝壳，回入口找老人用四份海盐和四个贝壳制作贝壳之铃。材料在各自采集点每天刷新。携带者在打出伤害后回复实际扣血量的八分之一。 |
| 变化洞、流星瀑布 | 登入丰缘名人堂后开放103号道路的变化洞和流星瀑布大吾洞。大吾用六只等级75至78的宝可梦迎战。绿岭市大吾家的球另有一只等级5的铁哑铃。 |
| 秘密基地 | 在111号道路找秘密之力训练家拿到招式学习器43。队伍有伙伴会秘密之力时，可以在75处原版岩壁、灌木或树洞开辟基地，对应24种室内。出门回到调查入口的那一格。 |
| 基地装饰 | 电脑提供摆放和收起。选好物品后走到目标格前按 A，回到电脑可取消。海报挂墙，玩偶和靠垫需要有对应承托位置的桌子或地垫。支持120种原版家具，其中45种使用独立的原版角色图。背包里的旧帐篷也可以摆放。搬家时收起摆设。 |
| 家具取得 | 104号道路花店、凯那集市、茵郁市和水静百货的10个柜台按原版商店清单出售。紫堇游戏角可用1000枚代币换御三家玩偶。工房用6000份灰换椅子、8000份灰换桌子。秋叶镇见过真由美后去她家领取莲叶童子玩偶，琉璃市民居可领吼吼鲸玩偶。学习版把水静百货楼顶的清仓活动安排在通关后的周六、周日。 |
| 110号道路海滨自行车道 | 从紫堇一侧骑音速自行车进入，向南过线后按完成时间和碰撞次数评分。成绩牌保留最快一趟，越野自行车可以通行。 |
| 训练家山 | 丰缘冠军在111号道路塔内选择普通、变化、独特、专家四条赛道。每条有四张原作楼层、八名训练家和各自视野，训练家的等级取队伍最高等级。大厅可恢复队伍。到屋顶与主人说话结算、本地存档记录各赛道最佳用时，电梯返回。 |
| 三遗迹 | 先经134号水路潜入布告石室，在外室北墙前用挖洞。内室让吼鲸王排第一、古空棘鱼排最后。在沙漠遗迹的指定位置碎岩、古代坟墓中心闪光、小岛横穴沿墙走完一周，可分别遇到三只等级40的守护者。114号道路化石迷家可向弟弟领取挖洞学习器。 |
| 异常天气 | 通关后询问天气研究所研究员，按报告前往日照岩壁或暴雨深水区。每类有八个原版地点。进入陆之窟、海之窟可遇到等级70的固拉多、盖欧卡。报告会在继续旅行时失效，可以重新询问。 |
| 漫游与天空之柱 | 通关后回未白镇家里查看电视，选择红色放出拉帝亚斯、蓝色放出拉帝欧斯。它在原版丰缘道路间移动，跨遭遇保留 HP、状态及招式 PP。天空之柱顶在双神事件结束后能够与等级70的烈空坐对战。 |
| 四张活动票 | 学习版将原来需要配信的活动统一交给水静港大厅的水手。冠军可选领取，向港务前台出示船票。南方孤岛是另一只无限宝可梦和心之水滴，肚脐岩是凤王与洛奇亚，诞生之岛要按步数限制移动三角岩，最遥远的孤岛在草丛追逐梦幻。四岛均可返港。 |
| 幻之岛 | 在暮水镇询问观岛老人。设备本地每天生成一个16位值，队伍中有匹配的伙伴时，130号水路会切成原作海岛地图，岛上有小果然与枝荔果树。匹配使用同一存档中每只伙伴持久化的随机值。 |
| 丰缘原野区 | 从121号道路入园，先领取丰缘宝可方块盒，再向接待员支付500元，使用30枚原野球探索500步。野生战可靠近、喂宝可方块、投球、离开。喂食器消耗盒内方块，余球和步数随存档保存。成为冠军后开放东北、东南扩建区。 |
| 记者、交换与收藏 | 记者玛莉和达伊在111、118、120号道路循环迁移，前六次逐步更换双方阵容，之后可继续双打并接受采访。原版四处 NPC 交换的要求分别为拉鲁拉丝换橡实果、 电萤虫换正电拍拍、宝贝龙换墨海马、向尾喵换喵喵。收集丰缘地区200种并向小田卷博士报告，可以从研究所桌上的菊草叶、火球鼠、小锯鳄中选一只。釜炎镇老人另有小果然蛋。 |

## 测试

- `tools/test_emerald_side_journey.py --godot GODOT --entry-save CHAMPION.json --result-save RESULT.json` 从已在正式流程打赢联盟的存档开始，步行到连胜之家四连战、两处冠军洞穴、大吾战和八关机关屋。脚本实际输入移动、推石、答题、踏板、密码门和领奖。随后到109号道路海滨之家打赢三位训练家并买汽水，到凯那市登记首位伙伴的努力奖章，再向暮水镇的同好会会长弟弟领取亲密度学习器。随后到123号道路向树果名人领树果，到华丽大赛大厅取方块盒并完成混合机，再去水静中心轮流见三人，实答一道题、送出一份收藏、喂掉亲手混出的方块。可加 `--pack` 针对导出的游戏包运行。
- `godot --headless --path . --script tools/test_emerald_side.gd` 在独立存档逐一验证原始地图场景、家具图、取得和使用道具、潮汐、地图迁移与传说触发。该套件会把玩家放到事件旁边，测试特定奖励时可直接结算战斗。它不计作从未白镇徒步走到每一个活动岛或实际捕获了所有传说宝可梦。
- `tools/test_emerald_hill_journey.py` 从本轮未白镇新档的冠军存档出发。普通、变化、独特、专家四条赛道均走完四层，与挡路训练家正常战斗，在屋顶领到奖品并将四条纪录保存到同一个档。专家路线的复活与疗伤道具来自旅途中战斗奖金和入口商店。计时采用设备时钟，自动输入记录的用时不能代表玩家实际挑战时长。

- `godot --headless --path . --script tools/test_emerald_lilycove_lady.gd` 从单独的新档核对六个 ID 尾数、现场三人的出现和离开、16道题及奖品、六类收藏奖、方块反馈、一次性电视节目、信件读写与贵重物出售。

原作核对使用 [pokeemerald 地图脚本](https://github.com/pret/pokeemerald/tree/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/data/maps)、[训练家山赛道](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/data/battle_frontier/trainer_hill.h)、[秘密基地原始坐标](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/secret_base.c) 和[三遗迹机关](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/braille_puzzles.c)。

## 实现边界

秘密基地已具备单人建设、迁移、购物和装饰。交换朋友基地的混合记录、外部活动配信和原卡带无线通信没有网络实现。梦幻的草丛追逐、记者简短采访、原野区方块口味与时间限量促销使用本项目的单人交互。训练家山保留了原地图、敌队、视野、等级与计时奖品，音符或闪光地板等部分演出仍有差异。各家具图都能摆放，气球爆破、滑梯和音乐地垫等演出仍有差异。水静女士保留训练家 ID 初始分型。为了让单机档能见到三人，可以主动交换本地活动记录，或等到次日再给同一人送礼。自订问答支持同一台设备交给身边的同伴作答。三地区共享存档及队伍，支线进度写在对应地区的标记中。
