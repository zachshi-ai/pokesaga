# 武斗镇流行语与紫堇老人

## 在武斗镇投稿

找会馆外的少年。他问现在的流行语对不对。选「我听说了别的流行语」，便可从分类词库选两个词并确认投稿。首次提出一组全新的词，少年会立刻采纳。再次投稿时，岛上按热度评选。镇上同时记住五组，热度每天变化，退出游戏的日子也计入。会馆里的人、书架、挂画会跟着当前第一名换词，部分人物会觉得快退潮的话题听腻了。词库有1,815个原词条及中文显示。见过的丰缘宝可梦、殿堂后的招式组、全国图鉴和学来的流行用语各有解锁条件。[武斗镇原版脚本](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/data/maps/DewfordTown/scripts.inc) · [流行热度算法](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/dewford_trend.c)

119号道路有447个编了号的水格。当前话题的种子选出六个号码，原作允许重复，跳过最北端不可到达的前三格。在选中的水格用任一钓竿有一半机会遇到20至25级丑丑鱼。第一次投稿替换榜首的文字，保留种子。以后其他话题跃居第一，就用新榜首的种子计算。[钓鱼位置、概率与等级](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/wild_encounter.c)

## 去紫堇市宝可梦中心拜访

同一份单机存档在一楼遇到其中一位。看训练家编号最后一位就能知道是哪一位。五种身份都沿用原作在此地指定的老人外形。

| 编号末位 | 老人 | 可以做的事 |
| --- | --- | --- |
| 0、1 | 吟游老人 | 听完六个词的歌，选一个位置更换歌词。听他试唱，可以重新改。满意后确认，今后再来就听到新歌。演唱用原作的音素采样和每词曲谱。 |
| 2、3 | 时髦老人 | 教一个流行用语，词立即收入组合词库。再次拜访会记得自己已经教过。 |
| 4、5 | 交换老人 | 夜巡灵玩偶、精灵球靠垫、轮胎或漂亮的花任选一件，用自己闲置的基地装饰交换。确认后从库存扣除，收到的装饰可在电脑摆放。 |
| 6、7 | 说书老人 | 记录主角达到门槛的实际游戏经历。从保存、训练家战斗、钓鱼、捕获、进化、孵蛋、翻阅图鉴或投稿等已记录行为中选一个讲述。今后同一个数字提高了，他会更新这段传说。 |
| 8、9 | 开心老人 | 聊宝可梦、招式、爱好或生活，在固定提问和随机词句间切换。无论回答是或否，都可能接着聊。每句有一成机会结束，一次最多十段。 |

原版中，联机混合记录可以带来其他玩家的老人、装饰库存和传说。本项目提供上述五种本机身份及各自的回访记录。同一存档由训练家编号固定身份。旧档首访会建立记录，游戏从有统计记录时起累计说书素材。[老人原版事件脚本](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/data/scripts/mauville_man.inc) · [身份分配、说书与演唱](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/mauville_old_man.c) · [四件原始装饰](https://github.com/pret/pokeemerald/blob/9103e529c2fbdd7add4a1ff3350c6c1f92112c42/src/trader.c)

`tools/test_emerald_fan_club.gd` 用统一新档进入丰缘后，分场景按 A 与少年、会馆居民、书画和老人互动。测试使用不同编号覆盖五类老人，检查演唱音轨、词库和道具变化，实际在119号道路用破旧钓竿钓出丑丑鱼，最后核对存档。完整数据可用 `python3 tools/import_emerald_fan_club.py /path/to/pokeemerald` 重建。
