# 阿罗拉地图

同一份存档从美乐美乐岛小悠的房间开始阿罗拉旅程。房间内的墙上地图可以打开全景图。好奥乐市设有地区领航员；好奥乐港口、慷待市、马利埃静市、以太乐园和海洋居民之村之间的船线随剧情开放。靠近路口、渡口或房门时会出现目的地名称。进入后小悠站在门边的可行走格，可以转身返回。

游戏有 195 张阿罗拉地区地图，计入 15 座带治疗、商店和电脑的宝可梦中心。另有三张与其他地区或特殊空间相接的过渡地图。地区内外共 426 个定向出口。114 张地图使用《太阳／月亮》四岛场景或其中的独立房间、洞穴，另外 81 张按游戏所需的楼层和目的地绘制。源数据包含四个整岛模型和 71 个分区模型。游戏内地图可以离线使用。[原场景、地点和野外资料](https://3ds.pzfans.com/pokemon-sun-moon/pokemon-sun-moon-alola-map/)

四岛场景按水平坐标投影到四方向步行格，转换比例为每 100 个场景单位一格。原地图记录用来确定城镇所在位置、道路走向、草丛范围，以及 372 个拾取点和 180 个训练家站位的参考坐标。场景相互覆盖，分区边缘并非原版地图的切屏线。原资料缺少可直接复用的门编号和脚本传送坐标，房门、船位及对岸落点按相邻地点重新布置。三维建筑、地貌和洞窟保留轮廓；步道、海岸、水面、可辨识的街面设施与卧室家具沿用工程里的绿宝石图块。

《究极之日／究极之月》新增的海滩、究极大都会、大都会塔、各究极异兽栖地与彩虹火箭队城堡均有独立区域。版本及剧情决定可以走哪条路。大浪海滩南侧的通海洞穴有水池、礁石及怪力填坑机关。拉普拉斯能载小悠登上中央小岛取得大珍珠；巨牙鲨能破开东南礁石取得光之黏土；北岸的石块推进坑内才可拿取招式学习器 24「十万伏特」。[通海洞穴地点与道具图鉴](https://www.serebii.net/pokearth/alola/sandycave.shtml)

通过卡奇的考验后，按 Start 打开「工具」并选择「宝可度假地」可以乘喷火龙抵达五岛，也可走慷待市的码头。悠悠岛上的豆树会随时间落豆；野生访客按原作的版本和巡礼阶段出现。速速岛可培育树果，怦怦岛可派宝可梦进洞寻宝，欢欢岛以每半小时一次的训练增长经验或努力值，暖暖岛可让伙伴增进亲密度，也能孵化寄放屋的伊布蛋。投入普通、花纹或彩虹豆可以在有效期间加速工作。岛屿设施按电脑箱中的伙伴数和普通豆数量开发，任务和送去度假的伙伴属于同一存档。关闭游戏期间经过的真实时间会在下次访问时结算。点菜单里的「返回出发地点」能回到乘喷火龙之前的位置。[太阳／月亮五岛资料](https://www.serebii.net/sunmoon/pokepelago.shtml) [究极之日／究极之月五岛资料](https://www.serebii.net/ultrasunultramoon/pokepelago.shtml)

《究极之日／究极之月》的好奥乐市、可霓可市各有一间摄影俱乐部。和队伍中的伙伴合照时，可以选背景、姿势与边框，在预览画面上点击贴纸的位置。保存后得到本机 PNG；在两个馆内、背包里的阿罗拉相册或重新启动游戏后都能翻看。伊利马在联盟后的考验向导服委托也会解锁馆内更衣，小悠换装后在地图与相片中穿同一套衣服。[官方摄影俱乐部介绍](https://www.pokemon.com/uk/strategy/alola-impresses-with-new-activities)

在马利埃庭园击败古兹马之后，登上辉克拉尼天文台的观测室可以挑战四级虫电宝充电盘。按左上、右上、左下、右下四个磁铁会旋转对应的四格和虫电宝朝向。每局最多四步。通电时解锁下一级，超级困难首次通关给 PP 极限提升剂。[天文台挑战与奖励](https://www.gamerguides.com/pokemon-ultra-sun-moon/guide/walkthrough/ulaula-island/back-to-earth/team-skull-boss-guzma)

## 美乐美乐岛的街道与民家

利利小镇的中心是八角形的木制祭台。哈拉的家在西北，沿屋前土路向北进入马哈罗山路，往南经过另外三户居民可回到 1 号道路。四户都有门槛、室内、居民和回到自家门外的落点。祭台按《太阳／月亮》的场景用途重画，房屋外观是新绘的像素茅屋，室内分别采用绿宝石武斗镇、茵郁市和暮水镇的格局。[原场景参考](https://3ds.pzfans.com/pokemon-sun-moon/pokemon-sun-moon-alola-map/) · [绿宝石茵郁市地图工程](https://github.com/pret/pokeemerald/tree/master/data/maps/FortreeCity)

好奥乐的商店街从宝可梦中心通往购物中心和马拉萨达店。旅游服务中心在喷泉旁，市政府在南侧，去码头会经过警察局。八处门的路面与门内落点分别配对。四个版本都能进糕点店花 350 元买大马拉萨达；「阿罗拉摄影俱乐部」仍按究极版开放。商场、糕点店和旅游服务中心使用水静市、凯那市的完整建筑轮廓。路灯、喷泉、店门台阶及铺砖按街面位置放置。[绿宝石凯那市地图工程](https://github.com/pret/pokeemerald/tree/master/data/maps/SlateportCity) · [绿宝石水静市地图工程](https://github.com/pret/pokeemerald/tree/master/data/maps/LilycoveCity)

1 号道路宽 139 格、高 65 格。通往利利小镇、好奥乐市郊和 3 号道路的步道按原有可走格连续铺设。1 至 17 号道路统一重绘路缘、草地、海岸和材质，后段仍依据原有场景投影与共用绘制规则生成。马哈罗山路和好奥乐市商店街作了单独布置。4.63 又重画了 1 号道路的海崖以及其余城镇、考验场、室内和究极空间。四座守护神遗迹使用各自的祭坛和地面，皇家巨蛋与联盟各房间有独立的战斗场地。可霓可市的丽姿宝石店、马利埃图书馆、慷待市观光服务处和欧哈纳镇餐厅均可原门往返。[本轮地图与对照画面](后世代地图重绘.md)

## 重建和验证

本机需安装 Python 3、Pillow、NumPy、SciPy、meshoptimizer、C 编译器和 Godot。首次运行会下载所需的公开场景，后续可复用同一缓存。美术已依赖的绿宝石室内图块随项目提供。

```sh
python3 tools/build_alola_surfaces.py /tmp/alola-fields --jobs 4
python3 tools/build_alola_maps.py /tmp/alola-fields
python3 tools/test_alola_maps.py
godot --headless --editor --import
godot --headless --script tools/test_world_walks.gd
godot --headless --script tools/test_world_returns.gd
godot --headless --script tools/test_alola_pelago.gd
godot --headless --script tools/test_alola_photo_roller.gd
python3 tools/test_alola_field_trip.py /path/to/earned-ultra-save.json
python3 tools/test_alola_streets.py /path/to/earned-ultra-save.json
```

地图检查以玩家落点为起点，按实际碰撞和水面检查每个双向出口、普通训练家、拾取物、剧情和支线交互站位。通海洞穴额外检查没有坐骑、仅能冲浪、配合巨牙鲨、配合怪力以及三者齐备时能拿到的道具。全地区步行检查另行通过游戏引擎重放跨区路线。
