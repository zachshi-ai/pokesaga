# 从化朗镇到草之徽章

4.64 在原来的冒险里接入《剑／盾》第一段道馆挑战。第一次前往伽勒尔时选择版本和队伍安排。带队可保留原有的 12 只，寄存则把队员逐只送进原来的电脑。小悠、图鉴、资金、其他地区的徽章和名人堂都沿用原存档。旧档若正停在还没有伽勒尔剧情的地图上，升级后从化朗镇家里办理首次抵达。

## 沿路可以做什么

| 地点 | 剧情和操作 |
| --- | --- |
| 化朗镇、木杆镇车站 | 在家找赫普，去赫普家，再到站外接丹帝。回化朗镇选敲音猴、炎兔儿或泪眼蜥。队伍满员时，新搭档送入电脑，赫普初战仍会由它上场。 |
| 微寐森林、木杆镇、２号道路 | 救走散的毛辫羊。雾中出现的宝可梦随版本变化。向索妮亚领图鉴，丹帝在２号道路示范捕捉。到木兰博士家接受推荐，许愿星做成极巨腕带。 |
| 旷野地带、机擎竞技场 | 搭列车出发，从旷野进入机擎市。先领联盟卡，再到竞技场登记自己的 1～3 位球衣背号。 |
| 含羞苞旅店、开幕式 | 随索妮亚看英雄像，处理呐喊队的单打和双打，见到玛俐。开幕式上《剑》有彩豆和玛瓜，《盾》有欧尼奥和美蓉。聂梓缺席。 |
| ３号道路、矿山、４号道路 | 告别赫普，领离洞绳，经过矿山时挑战彼特。沿路可对战训练家，遇见野生宝可梦。４号道路遇见追毛辫羊的亚洛。 |
| 草路镇、地画观景台、草路竞技场 | 跟上来电汪去见索妮亚。随后在道馆柜台登记，用方向键把各片牧场的羊群送进草垫。与亚洛对战时，幼棉棉为 Lv.19，白蓬蓬为 Lv.20。 |

道馆内每群画出五只毛辫羊。一片牧场的四群全部进圈，羊群会撞开草垛。来电汪会惊散羊群，赢过附近的训练家可以让它安静下来。草坪上与亚洛交手时，点战斗菜单里的「特殊行动」选择极巨化，每队每战一次，最多三回合。击败亚洛后可以回到其他地区再回来，草之徽章单独记在伽勒尔。

## 这段剧情的道具

| 道具 | 从哪里拿 | 能做什么 |
| --- | --- | --- |
| 伽勒尔宝可梦图鉴 | 木杆镇研究所的索妮亚 | 打开同一份存档里的图鉴，保留已经记录的形态。 |
| 推荐函、许愿星、极巨腕带 | ２号道路的丹帝和木兰博士 | 推荐函用于报名。许愿星在隔天换成腕带，在草路馆主战启用极巨化。 |
| 露营组合、宝可梦盒 | 出发的车站、旷野地带 | 在户外扎营，拿树果做咖喱恢复队伍。宝可梦盒可存取伙伴，进行牧场任务和馆主战时需先回大厅。 |
| 高速星星、魔法叶 | 出发去旷野时、获胜后的亚洛 | 可重复教学，学习时从队员中选择。 |
| 奇迹种子／木炭／神秘水滴 | 机擎市的丹帝 | 礼物随初始搭档的属性变化。 |
| 飞翔出租车、伽勒尔离洞绳 | 开幕式后、３号道路 | 出租车可返回在本章解锁的地点。离洞绳从矿山返回入口，可重复使用。 |
| 丹帝、赫普、亚洛的联盟卡 | 机擎市、前往３号道路之前、草路镇观景台 | 从背包查看人物资料。 |
| 草之徽章、草之套装 | 打赢亚洛 | 徽章存入本地徽章盒。使用套装给小悠换衣，再用一次换回原衣。 |

这一段包含 30 个剧情事件、19 名道路和矿山训练家，以及草路牧场的三名道馆训练家。4.65 从草之徽章继续前往水舟镇，接下七座道馆、冠军杯与扩展地区的剧情。[查看后续地区与玩法](伽勒尔冠军与扩展地区.md)

## 发布包实走

用最终签名 APK 里的游戏资源走了以下路线。两条完整路线都经过赶羊和亚洛战，随后返回出发地区，完全关闭游戏，从标题继续，再次返回伽勒尔。

| 存档 | 实际结果 |
| --- | --- |
| 空槽新建，关都 →《剑》 | 在关都拿到小刚徽章后寄存原队伍。伽勒尔实际用露营组合和树果做咖喱，收服幼棉棉，让队员学会魔法叶和高速星星，穿上再脱下草之套装。返回关都重启后，两地各自的第一枚徽章都在。 |
| 4.63 阿罗拉旧档 →《盾》 | 原队有 12 只，已有 24 枚其他地区徽章和 1 个阿罗拉印章。在本章挑战了 19 名道路、矿山训练家及 3 名道馆训练家。返回阿罗拉重启后，核对了队员身份、箱子、各地徽章和阿罗拉剧情进度。 |
| 满队寄存 | 原箱 52 只，加上队伍 12 只，寄存后为 64 只。领泪眼蜥后，队伍只有这只新伙伴。 |
| 旧档已停在化朗镇 | 4.63 的伽勒尔探索档从标题继续后出现首次抵达选项。分别选择带队、寄存，都保留原有资金、图鉴和剧情标记。重新读档保留所选版本和落点。 |

Android ARM64 模拟器覆盖安装后，读取的存档文件与升级前逐字节一致。最终设备上的 APK 校验值与 GitHub 下载包见发布说明。[安卓触屏画面](../.github/preview/v4.64-galar.png)

## 资料与复现

机擎市旅店和竞技场、草路牧场及比赛场地使用 16 像素网格重绘。部分馆主和劲敌的图集取自 Emerald Rogue 的伽勒尔人物，索妮亚、木兰博士、洛兹等按绿宝石人物的帧规格重新配色及绘制。剑盾等级招式来自 PokéAPI 的第 20 版本组，按名称映射到本作的招式编号。[伽勒尔官方介绍](https://swordshield.pokemon.com/en-us/people-galar-region/gym-leaders/) · [人物素材版本](https://github.com/Pokabbie/pokeemerald-rogue/tree/5ccb74cf1ef2c0349dfa5d70883b030bbc9ff803) · [PokéAPI 原始表](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)

可运行 `tools/test_galar_journey.py` 重放旅程。它通过游戏的方向键、对话、战斗和菜单来驱动进度。加 `--version sword --transfer boxed` 从新档开始，加 `--version shield --transfer carried --resume 旧档.json --require-full-party` 检查 12 只满队旧档。另有 `tools/test_galar_entry.gd` 检查未完成条件时直达道馆、使用外区秘传招式和重启的行为。
